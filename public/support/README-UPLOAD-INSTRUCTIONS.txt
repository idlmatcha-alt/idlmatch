IDMatch AI Support + Admin Panel
================================

This package is a SAFE, standalone starter package designed to be uploaded to a typical Hostinger PHP website.
It does not overwrite your existing homepage or database files.

FOLDER TO UPLOAD
----------------
Upload these two folders into your website document root:

public_html/
  admin/
  support/

After upload:
  https://idlmatch.com/admin/
  https://idlmatch.com/support/ (API endpoint, not a page)

IMPORTANT
---------
1. Make a full backup of public_html before uploading.
2. The admin UI currently uses demo/sample statistics stored in admin/api/data.php.
3. It does NOT automatically connect to your existing IDLMatch database, because the existing application/database schema was not supplied.
4. Before using the admin panel for real customer data, connect the data adapter to your existing database and existing admin authentication.
5. Do NOT put an OpenAI API key in JavaScript. Put it only in support/config/config.php.
6. The support agent can work in demo mode if no API key is configured. In demo mode it returns a helpful fallback message.

HOSTINGER PATH
--------------
In Hostinger File Manager, open:
Websites > idlmatch.com > File Manager > public_html

Upload the ZIP, extract it, then move/copy the extracted /admin and /support folders directly into public_html.

If you already have a folder named /admin, do NOT overwrite it blindly. Rename the existing folder first (for example admin-backup) or upload this package to /idlmatch-admin-preview instead.

OPENAI CONFIGURATION
--------------------
Edit:
  public_html/support/config/config.php

Set:
  OPENAI_API_KEY = 'YOUR_SERVER_SIDE_API_KEY'

The current default model in this package is gpt-5.6-luna, which is intended for cost-sensitive, high-volume workloads. Change it there if you prefer another available model.

ADMIN ACCESS
------------
This starter panel includes a setup guard rather than insecure default credentials.

Edit:
  public_html/admin/config/config.php

Set an ADMIN_PASSWORD_HASH generated by PHP:
  <?php echo password_hash('YOUR-STRONG-PASSWORD', PASSWORD_DEFAULT); ?>

Run the one-line PHP command in a temporary local PHP environment, or create a temporary file on hosting, load it once, copy the output into config.php, and delete the temporary file immediately.

Then open /admin/login.php.

DO NOT paste a raw password into config.php.

SUPPORT WIDGET INSTALLATION
---------------------------
Add this one line before </body> on the public-facing IDLMatch pages:

<script src="/support/assets/widget.js" defer></script>

If your website already loads a global JS bundle, you can load this script there instead.

CUSTOMIZE BRANDING
------------------
Edit:
  support/assets/widget.css
  support/assets/widget.js
  admin/assets/style.css

SECURITY NOTE
-------------
This package is intended as an uploadable frontend/backend starter. For production use, connect the existing user/account data securely, add CSRF protection for any write actions, enforce your current session/authentication system, and log/limit support requests.
